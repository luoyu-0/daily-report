# 领域文档

本文件说明工程技能在探索代码库前应如何读取领域文档。

## 探索前读取

- 读取仓库根目录的 `GLOSSARY.md`
- 如果存在 `GLOSSARY-MAP.md`，读取其中指向的相关上下文词汇表
- 读取 `docs/adr/` 中与当前工作相关的 ADR

如果这些文件不存在，静默继续，不把缺失本身视为问题。领域建模技能会在术语或决策实际明确后按需创建它们。

## 文件结构

本仓库采用 single-context 布局：

```text
/
├── GLOSSARY.md
├── docs/adr/
└── src/
```

## 使用统一术语

问题标题、重构建议、假设和测试名称应使用 `GLOSSARY.md` 定义的领域术语，避免使用词汇表明确排除的同义词。

如果所需概念尚未记录，应先判断它是否属于不必要的新术语；若确实存在领域空缺，则交由领域建模流程补充。

## 标记 ADR 冲突

如果方案与现有 ADR 冲突，应明确指出冲突及重新讨论的理由，不得静默覆盖既有决策。
